# Изменения

## 0.2.0

- Поиск больше не требует API-ключа, регистрации или оплаты поискового API.
- Удалены поле Brave API key, получение ключа и кнопка поиска в браузере.
- Публичные упоминания загружаются из RSS-выдачи Bing непосредственно в таблицу приложения.
- Посторонние ссылки отбрасываются: в заголовке, выдержке или URL должны присутствовать введённые данные.
- Ошибки, перенаправления и ограничения источника не выдаются за отсутствие аккаунтов.
- Сохранены проверки публичных страниц Telegram/TikTok по никнейму, заметки и экспорт JSON.

## 0.1.0

Первая версия с Brave Search API, проверками Telegram/TikTok и экспортом отчёта.
