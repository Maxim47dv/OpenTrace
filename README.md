# OpenTrace

[Скачать OpenTrace.exe](https://github.com/Maxim47dv/OpenTrace/releases/latest/download/OpenTrace.exe) · [Все релизы](https://github.com/Maxim47dv/OpenTrace/releases) · [Сборка и тесты](https://github.com/Maxim47dv/OpenTrace/actions)

Windows-приложение для поиска **публичных упоминаний** телефона, почты или никнейма на страницах соцсетей. Результаты, выдержки источников и заметки отображаются внутри приложения.

**В версии 0.2 API-ключ, регистрация и оплата поискового API не нужны.**

## Как пользоваться

1. Запустите `OpenTrace.exe` на Windows 10/11 с .NET Framework 4.8 и доступом в интернет.
2. Выберите «Телефон», «Почта» или «Никнейм».
3. Введите телефон с `+` и кодом страны, полный адрес почты или никнейм без ссылки.
4. Нажмите «Найти» и дождитесь результатов в таблице. Кнопка «Стоп» отменяет поиск.
5. Выберите строку — внизу появятся источник, URL, выдержка и время проверки.
6. При необходимости сохраните свою оценку и заметку кнопкой «Сохранить оценку».
7. Кнопка «Экспорт JSON» сохраняет отчёт на диск. Несохранённые результаты исчезают при закрытии.

Браузер не открывается при поиске. Только кнопка «Источник ↗» открывает выбранную найденную страницу по вашему нажатию.

## Источники

- Публичная RSS-выдача Bing: ссылки на Telegram, TikTok, Instagram, VK, Facebook, X, GitHub, Reddit, YouTube и `wa.me`.
- По никнейму: отдельная проверка публичной карточки Telegram и TikTok oEmbed.
- Отбрасываются ссылки вне списка сервисов и результаты, где исходные данные не встречаются в заголовке, выдержке или URL.

RSS-выдача Bing — публичный веб-интерфейс, а не платный API с гарантией доступности. Количество результатов ограничено самим источником. Он может менять формат, игнорировать поисковые операторы или ограничивать запросы. В этом случае приложение показывает ошибку или частичный результат и не обходит ограничения доступа.

## Что означают результаты

«Публичное упоминание» — исходные данные присутствуют в доступном поисковом результате. Выдержки могут быть устаревшими или относиться к другому человеку. Совпадение **не доказывает принадлежность аккаунта**.

«Публичная страница» — Telegram или TikTok подтвердил доступную карточку с никнеймом. В Telegram это может быть пользователь, группа, бот или канал. Карточка без фото может остаться неподтверждённой. Совпадающие никнеймы в разных сервисах не устанавливают общего владельца.

Пустая выдача и статус «Не удалось проверить» не доказывают отсутствие аккаунта. Проект не получает скрытые привязки к телефону или почте. WhatsApp представлен только публично индексируемыми ссылками `wa.me`; регистрации номера, импорта контактов и сообщений нет.

## Данные и сеть

Введённые данные отправляются Bing в поисковом запросе. При проверке никнейма он дополнительно передаётся Telegram и TikTok. Нет телеметрии, истории запросов, встроенных ключей, баз утечек и автоматического сохранения отчётов.

JSON-отчёт содержит исходный запрос, найденные выдержки, ссылки и ваши заметки. Реальные отчёты не следует добавлять в публичный репозиторий.

## Сборка

Из папки проекта в PowerShell:

```powershell
./build.ps1 -Test
```

Готовое приложение появится в `dist/OpenTrace.exe`. NuGet и сторонние библиотеки не требуются. GitHub Actions выполняет сборку и тесты автоматически.

## Проверки версии 0.2

27 тестов движка проверяют RSS, фильтрацию посторонних результатов, формат телефона, границы совпадения почты, подмену доменов, XML без внешних сущностей, ошибки источников, отмену и консервативную проверку профилей. Сценарий интерфейса проверяет поиск без ключа, вывод результата и сохранение заметки.

В сетевой проверке этой версии RSS Bing успешно прочитан без ключа; публичная страница Telegram и пример профиля TikTok из документации также проверены. Доступность сервисов в другой сети может отличаться.
