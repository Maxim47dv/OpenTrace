# OpenTrace

[Скачать OpenTrace.exe](https://github.com/Maxim47dv/OpenTrace/releases/latest/download/OpenTrace.exe) · [Все релизы](https://github.com/Maxim47dv/OpenTrace/releases) · [Сборка и тесты](https://github.com/Maxim47dv/OpenTrace/actions)

Windows-приложение для поиска **публичных упоминаний** телефона, почты или никнейма на страницах соцсетей. Результаты содержат ссылку, текст из источника, время проверки и оценку пользователя.

Это самостоятельный небольшой проект, не SpiderFoot и не его модуль. Программа не получает скрытые привязки аккаунтов к номеру или почте.

## Возможности

- Поиск публичных упоминаний через официальный Brave Search API: Telegram, TikTok, Instagram, VK, Facebook, X, GitHub, Reddit, YouTube, WhatsApp (`wa.me`).
- Для никнейма: дополнительная проверка публичной карточки Telegram и TikTok oEmbed без поискового ключа.
- Раздельные статусы: поисковый кандидат, публичная страница, неполная проверка или ошибка источника.
- Источник и выдержка из поисковой выдачи; ручная оценка связи и заметка.
- Остановка запроса и экспорт JSON без ключа API.
- Поиск в браузере без ключа.

В WhatsApp программа ищет только публично индексируемые ссылки `wa.me`. Она не проверяет регистрацию номера, не импортирует контакты и не отправляет сообщения.

## Запуск

Требования: Windows 10/11, .NET Framework 4.8, доступ в интернет. Запустите `OpenTrace.exe`.

1. Выберите тип данных и введите номер с `+` и кодом страны, адрес почты или никнейм без ссылки.
2. Для автоматического поиска публичных упоминаний вставьте **свой** ключ Brave Search API в поле `Brave API key`. Кнопка получения ключа открывает официальный сайт сервиса. Доступ и стоимость определяются вашим тарифом Brave.
3. Нажмите «Найти». Без ключа работают проверка Telegram/TikTok по никнейму и отдельная кнопка поиска в браузере.
4. Выберите строку: внизу появятся ссылка и доказательство. Оценку и заметку сохраняйте кнопкой «Сохранить оценку».
5. Сохраните JSON, если нужен отчёт. При закрытии приложения несохранённые результаты исчезают.

Ключ не требуется передавать разработчику или вводить в чат. Он хранится только в памяти текущего окна и не включается в отчёт.

## Что означают результаты

«Кандидат из поиска» означает, что поисковик вернул страницу по запросу. Выдержка может не содержать исходный номер/адрес, быть устаревшей или относиться к другому человеку. Программа не заявляет, что принадлежность аккаунта установлена.

«Публичная страница» подтверждает наличие доступной карточки с никнеймом. Одинаковые никнеймы в разных сервисах не доказывают общего владельца. В Telegram карточка может принадлежать боту, группе или каналу. Проверка Telegram консервативна: карточка без фото может остаться неподтверждённой.

Пустая выдача, блокировка, ошибка сети, HTTP 403/429 или неподтверждённая страница не доказывают отсутствие аккаунта. Поиск ограничен первыми 20 результатами одного запроса; это не полный перечень упоминаний.

## Данные и сеть

- При автопоиске номер, почта или никнейм передаются Brave в поисковом запросе. При поиске по никнейму он также передаётся Telegram и TikTok.
- Ключ передаётся Brave в заголовке, а не в URL. Автоматическое следование перенаправлениям отключено.
- Внешние страницы и кнопка браузерного поиска открываются только по нажатию пользователя.
- Нет встроенной телеметрии, истории запросов, хранения ключей, баз утечек или автоматического сохранения отчётов.
- Отчёт содержит введённые данные и выдержки. Храните его локально; не добавляйте реальные отчёты и ключи в публичный репозиторий.

## Сборка и тесты

В PowerShell из папки проекта:

```powershell
./build.ps1 -Test
```

Готовый файл: `dist/OpenTrace.exe`. Сборка не требует NuGet и сторонних библиотек. Тесты используют синтетические ответы, проверяют ошибки API, отмену, подмену доменов, неоднозначные ответы платформ и исключение ключа из отчёта; реальных людей не ищут.

GitHub Actions автоматически собирает приложение и запускает тесты. Готовую пользовательскую версию можно скачать в разделе Releases. Для своего варианта проекта создайте fork репозитория.

## Проверка этой версии

Пройдены 26 автоматических проверок движка и проверка интерфейса: отображение результата, сохранение оценки и заметки, сохранность цели отчёта при ошибочном вводе. Ответы Brave в тестах синтетические; живой запрос к Brave не выполнялся, поскольку пользовательский ключ не предоставлен.

При отдельной сетевой проверке публичная страница канала `telegram` успешно прочитана. Пример TikTok `scout2015` из документации oEmbed не подтвердился в этой сети; приложение оставило статус «Не удалось проверить». Это не означает, что страницы не существует.
